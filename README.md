# 🚗 Location-Voiture

Bienvenue dans **Location-Voiture**, une application web de location de voitures développée avec une architecture frontend/backend séparée.

## 🧰 Technologies utilisées

### Frontend
- HTML
- CSS
- JavaScript (Vanilla ou avec framework si précisé)

### Backend
- Node.js (ou préciser le framework utilisé : Express, Laravel, Django, etc.)

## 📁 Structure du projet

```bash
Location-Voiture/ │ 
├── Backend/ # Code backend (API, base de données, logique métier) 
├── frontend/ # Code frontend (interface utilisateur) 
```

## ⚙️ Installation et utilisation

### 1. Cloner le dépôt

```bash
git clone https://github.com/p99chakrounayoub/Location-Voiture.git
cd Location-Voiture
```

### 2. Backend

```bash
cd Backend
npm install       # installe les dépendances
npm start         # démarre le serveur backend
```
### 3. Frontend

```bash
cd ../frontend
# Ouvre index.html dans ton navigateur
# OU utilise un serveur local comme Live Server si nécessaire
```

🛠 Fonctionnalités principales

🔍 Recherche de voitures disponibles

📅 Réservation de véhicules avec choix de dates

👤 Authentification et gestion des utilisateurs

🛡️ Sécurité basique (auth, gestion des accès)

🎨 Interface utilisateur simple et intuitive
